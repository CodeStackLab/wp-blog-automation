# Auto Image Resizer for WordPress

A lightweight, fast WordPress plugin that automatically resizes images when uploaded to optimize your website's performance.

## Features

✅ **Automatic Resizing** - Images are resized on upload, no manual intervention needed
✅ **Multiple Format Support** - Works with JPEG, PNG, GIF, and WebP images
✅ **Aspect Ratio Preservation** - Maintains original image proportions
✅ **PNG Transparency** - Preserves transparent backgrounds in PNG images
✅ **Configurable Settings** - Customize max dimensions and JPEG quality
✅ **Lightweight & Fast** - No external dependencies, pure PHP
✅ **Memory Efficient** - Optimized for performance

## Installation

### Method 1: Manual Installation

1. Download the `auto-image-resizer.php` file
2. Upload it to your WordPress installation at:
   ```
   /wp-content/plugins/auto-image-resizer/auto-image-resizer.php
   ```
3. Go to WordPress Admin → Plugins
4. Find "Auto Image Resizer for WordPress" and click "Activate"

### Method 2: Direct Upload

1. Create a ZIP file containing `auto-image-resizer.php`
2. In WordPress Admin, go to Plugins → Add New → Upload Plugin
3. Upload the ZIP file and click "Install Now"
4. Click "Activate Plugin"

## Configuration

After activation:

1. Go to **Settings → Image Resizer** in WordPress Admin
2. Configure your preferred settings:
   - **Maximum Width**: Default 1920px (recommended for HD displays)
   - **Maximum Height**: Default 1080px (Full HD)
   - **JPEG Quality**: Default 85 (balance between quality and file size)

## How It Works

When you upload an image to WordPress:

1. The plugin checks if the image exceeds the configured maximum dimensions
2. If it does, the image is automatically resized while maintaining aspect ratio
3. The resized image is saved with optimized quality settings
4. Original aspect ratio and transparency (for PNGs) are preserved

## Recommended Settings

### For Blog/Content Sites
- Max Width: 1920px
- Max Height: 1080px
- JPEG Quality: 85

### For High-Performance Sites
- Max Width: 1600px
- Max Height: 900px
- JPEG Quality: 80

### For Image-Heavy Sites
- Max Width: 2560px
- Max Height: 1440px
- JPEG Quality: 90

## Compatibility

- **WordPress**: 5.0 or higher
- **PHP**: 7.0 or higher
- **Required PHP Extensions**: GD Library (usually enabled by default)

## Integration with WP Automation

This plugin works seamlessly with the WP Automation system:

1. Images generated by Runware.ai are automatically uploaded to WordPress
2. The Auto Image Resizer processes them on upload
3. Images are optimized to your configured dimensions
4. No manual intervention required

## Troubleshooting

### Images not resizing?

1. Check if GD Library is enabled in PHP:
   ```php
   <?php phpinfo(); ?>
   ```
   Look for "GD Support" = enabled

2. Verify file permissions on wp-content/uploads/

3. Check WordPress error logs for any issues

### Memory issues?

If you're processing very large images, increase PHP memory limit in wp-config.php:
```php
define('WP_MEMORY_LIMIT', '256M');
```
